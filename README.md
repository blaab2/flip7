# Flip 7 AI Challenge

Teams compete at the card game **Flip 7**, using AI to prepare.

## Format

1. **Prepare (1 hour):** each team develops a strategy and builds tools to help it win. Teams are especially encouraged to use AI.
2. **Play:** the teams play Flip 7 against each other.
